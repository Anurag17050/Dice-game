# 🎲 Dicee Game

A simple web-based dice game for two players. When the page is refreshed, two dice are rolled and the player with the higher number wins. In case of a tie, the result is a draw.

## 🖥️ Demo

Open `dicee.html` in your browser to play the game.

## 📜 How It Works

- Each time the page loads, two random numbers (1-6) are generated using `Math.random()`.
- These numbers determine which dice image is shown for Player 1 and Player 2.
- The JavaScript compares the two numbers and updates the heading (`<h1>`) to display the winner or a draw.

## 🌈 Technologies Used

- HTML5
- CSS3 (with Google Fonts)
- JavaScript (Vanilla JS)
